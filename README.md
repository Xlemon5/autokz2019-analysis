# Рынок автомобилей Казахстана и позиция «Меркур Авто»

Курсовой проект по дисциплине «Предподготовка и анализ данных». Автор: Задорожний Илья Владимирович, группа M26-555. Данные охватывают январь — сентябрь 2019 года.

## Файлы проекта

- [Тетрадь с кодом и результатами](03_Zadorozhnii_M26-555.ipynb) — вся очистка, проверки, анализ и встроенные графики
- [Отчет в PDF](03_Zadorozhnii_M26-555_report.pdf)

## Воспроизведение

Использована среда Python 3.11. Все преобразования находятся в тетради.

```bash
python3 -m pip install -r requirements.txt
jupyter lab 03_Zadorozhnii_M26-555.ipynb
```

Выполните ячейки сверху вниз. Последняя ячейка сохранит `autokz2019_clean.csv` и проверит совпадение данных после повторного чтения.

Исходный CSV использует точку с запятой и десятичную запятую. Итоговый CSV — UTF-8 с BOM, разделитель запятая, десятичная точка, даты YYYY-MM-DD, пропуски в виде пустых полей. Для анализа внутреннего рынка используется `is_export = False` и известное `quantity`. Для распределений дополнительно выбирается `quantity > 0`.

## Результаты и ограничения

Внутренний объем очищенной выборки — 34 725 автомобилей с учетом возврата. По полю компании «Меркур Авто» учтено 394 автомобиля, или 1,13% объема рынка. Средняя цена компании — 38 379,52 USD, всего рынка — 23 087,05 USD.

Полные совпадения исходных строк удалены по условию задания. Без идентификаторов сделок это остается допущением: в тетради показан альтернативный расчет с сохранением повторов.

Поля компании и дилерского центра задают разные отборы. Отбор по имени дилера Mercur Auto дает 712 автомобилей; объединение с отбором по компании без повторного учета — 813. Эти показатели относятся к разным правилам отбора записей, а принадлежность всех дилеров одной организации по выгрузке не устанавливается.

Графики находятся в тетради. Отдельного скрипта обработки не требуется.
